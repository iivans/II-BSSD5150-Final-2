# II-BSSD5150-Final-2

II-BSSD5150-Final-2 is a Unity project built upon the standard 2D template version 7.0.3. The application is registered under DefaultCompany with the product name II-BSSD5150-Midterm.

The project environment relies on a 2D physics configuration featuring a standard downward gravity of -9.81 on the Y axis. Player interactions and controls are defined within the InputManager, which maps horizontal and vertical axes, jump actions, primary and secondary fire controls, mouse tracking, and various debugging commands.

Navigation capabilities are supported via NavMesh project settings configured with a Humanoid agent type having a radius of 0.5 and a height of 2. Visual rendering is managed through customizable graphics settings that include deferred rendering pathways and default sprite materials. Editor preferences specify customized project serialization modes alongside package manager integrations linked to the official Unity package registry.
